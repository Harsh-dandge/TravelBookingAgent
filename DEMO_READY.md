❓ TROUBLESHOOTING:

Q: Browser shows "Connection refused"
A: Make sure demo_app.py is running (check terminal)

Q: Searches not working
A: Check if .env file has valid SERPAPI_KEY

Q: UI looks broken
A: Clear browser cache (Ctrl+Shift+Delete)

Q: Need to restart server
A: Press Ctrl+C in terminal, then run python demo_app.py again

Q: Want to change port number
A: Edit demo_app.py, change app.run(port=5000) to desired port
